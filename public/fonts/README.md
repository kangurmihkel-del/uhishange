# Locally bundled fonts

The unchanged WOFF2 subsets serve the CVI's Lora 600/700 headings and Work Sans 400/500/600 interface text. Latin and Latin Extended subsets include Estonian characters. The runtime makes no Google Fonts requests.

Retrieved on 2026-10-10 from the [official Google Fonts CSS API](https://developers.google.com/fonts/docs/css2), with normal style and display=swap. Lora uses the v37 files; Work Sans uses v24. The four files are original provider-distributed variable WOFF2 subsets, with no local font modification.
