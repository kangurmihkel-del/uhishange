# Visual identity

Owner: project maintainer. Source authority: the unchanged docs/Uhishange_CVI.docx supplied on 2026-10-10.

The portal uses the CVI's warm local identity throughout public entry, buyer, supplier and administrator views. Primary colors are forest #285443, warm background #F5F1E8, charcoal #272724, stone #D8D5CC, clay #C86848, sage #8EA98E and yellow #D8A945. Warm surfaces dominate; white/neutral cards, forest navigation and small accents support readable information. Cards use 8–12 px corners, simple line icons and flat community illustrations.

Lora 600/700 headings and Work Sans 400/500/600 interface text are bundled locally with their licenses. The portal must load its fonts without external requests. The strong ÜHISHANGE wordmark and simple three-house mark replace the existing layered technology mark. The main message is “Koos tellides tuleb parem hind.” Public service/process/provider navigation links to actual explanatory content and the main CTA reaches the existing account flow.

Participation uses filled/unfilled dots, exact confirmed-paid counts and a readable success moment. Large thresholds must not create hundreds of elements or page overflow. The display retains historical success when withdrawals reduce the current paid count. Color is accompanied by text, clear focus states and sufficient contrast. Clay is the normal geographic marker color; the procurement center, selected organization and supplier remain distinguishable through shapes, labels or outlines.

The CVI's illustrative per-visit prices and simplified process are visual examples. The implemented pilot retains gross whole-service prices per association, supplier selection before commitments, paid-only participation, TEST financial labels, locked history and its existing five-stage next-action flow. No business or database changes are required.

Acceptance: public navigation and CTA reach visible content/forms; locally bundled fonts actually load; participation displays exact paid counts and latched success; all existing buyer/supplier/admin/viewer workflows remain usable on desktop/mobile; no horizontal overflow or browser errors; visually inspect public entry, dashboard, procurement/map, mailbox, forms, contracts and administration.

Public information links and the account CTA reveal their focus target immediately. Successive activations must not leave the target offscreen by interrupting an earlier scrolling animation; link destinations and application routing remain unchanged.
