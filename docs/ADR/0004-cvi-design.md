# Warm local visual identity

Date: 2026-10-10. Owner: project maintainer. Status: accepted by the user's instruction to update the design from docs/Uhishange_CVI.docx.

Apply the supplied CVI to the existing React portal rather than replacing its functional screens. Centralize the palette, bundle licensed Lora and Work Sans fonts, reuse a wordmark/three-house logo component, and use accessible bounded dot participation indicators. Keep the SVG geographic discovery map and existing lifecycle actions. Flat surfaces and simple illustrations replace gradients and decorative technology motifs.

The original CVI document remains unchanged. The financial and authority rules take precedence over illustrative examples in the design brief. The design branch is based on the tested service-type branch while PR #3 awaits maintainer merge; the separate design PR targets that branch to keep its review limited to the CVI change.
